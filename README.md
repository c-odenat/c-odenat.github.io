# Nathaniel Darko — Personal Portfolio

Production-grade personal portfolio website for **Nathaniel Darko** — Full-Stack Developer, Software Product Builder, and AI & LLM Enthusiast based in Accra, Ghana.

Designed with a high-contrast *"Trading terminal meets editorial studio"* aesthetic: dark-first theme, electric emerald accents, subtle coordinate grid, monospace telemetry labels, interactive project preview modal, live typewriter role rotation, and responsive layout across mobile and desktop.

## 🚀 Live Demo
- **GitHub Pages**: [https://c-odenat.github.io/](https://c-odenat.github.io/)

## 🛠 Tech Stack
- **Structure & Logic**: Semantic HTML5, Vanilla JavaScript (ES6+)
- **Styling**: Vanilla CSS3 (Custom design system with CSS custom properties, responsive clamp scaling, glassmorphism modal, print & dark mode media queries)
- **Typography**: Space Grotesk (Display & Body) + JetBrains Mono (Telemetry & Labels) via Google Fonts
- **Assets**: Optimized profile imagery, SVG procedural mockups, Simple Icons CDN

## 💻 Local Development

Run with any local HTTP server:

```bash
# Python
python -m http.server 8080

# Node.js (npx)
npx serve .
```

Open `http://localhost:8080` in your browser.
